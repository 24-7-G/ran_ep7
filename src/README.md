# RAN ONLINE EP7 CLASSIC

Complete Vite + React project for the Boss Hunt Attendance dashboard.

## Run

```powershell
npm i
npm run dev
```

## Production build

```powershell
npm run build
```

## Deploy

```powershell
npm run deploy
```

Boss artwork is stored in `src/bosses/` and class emblems in `src/icons/`.
