CLEAN 19 — TREASURY DETAILS + REWARD CENTER POLISH

Based on CLEAN 18.

Changes:
- Treasury ledger rows are now clickable/focusable and open a compact ACTIVITY DETAILS modal.
- Treasury detail view summarizes action, amount, updater, update time, description, player/item mapping, direction, balance changes, admin reason and linked-system connections.
- Treasury detail presentation intentionally hides document IDs / UID-style identifiers.
- Treasury ledger sorting now uses UPDATED AT first, then transaction/created time, so the most recently updated records remain at the top.
- BH Reward Inventory sorting now uses UPDATED AT first, then CREATED AT, keeping the most recently changed reward records at the top.
- Reward Center visual layout polished without changing reward claim/business logic.
- Reward inventory is visually grouped into a header, filters, table and pagination shell.
- Reward action column and table widths adjusted to reduce clipping on normal desktop widths.
- Existing 10-per-page reward pagination is preserved.
- Existing claim history and reward detail modal are preserved.
